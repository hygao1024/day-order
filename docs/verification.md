# 界面验证参考

构建与基础验证命令见 [AGENTS.md](../AGENTS.md#构建与基础验证)。以下说明真实应用截图、专项检查的覆盖范围和限制；按改动选择所需检查。

## 运行条件与结果

冒烟验证需要已登录的 macOS 图形会话，会短暂打开真实菜单栏弹窗，生成浅色、深色、六行月份、设置及公历节日与世界日显示／隐藏／重合、世界日长名称截图，以及连续日期区的小幅滚动、跨月选择不跳动、返回位置、范围边界、年概览、跨年滚动、年份输入错误与重复跳转、月份点击、星期日起始、菜单栏显示模式、单／双位日期图标截图与 `result.txt`，以及放假、补班、关闭标记和未收录年份截图，然后退出。它使用隔离的设置域，不改变日常偏好；合成输入阶段固定浮层，防止自动化宿主抢焦点，尾部偏好与材质回归恢复生产环境的临时弹窗行为，不覆盖物理点击外部关闭。仅 Debug（调试）构建支持此参数。截图用于人工检查布局，不代表 VoiceOver（旁白）或所有系统版本已经验证。

`run-smoke.py` 使用已构建的应用，保留全部运行输出到目标目录的 `runtime.log`，同时检查应用退出码和 SwiftUI 布局循环诊断；功能断言通过但日志包含 `AttributeGraph: cycle detected` 时仍判为失败。单次运行超过 300 秒会终止并报告失败。下列专项参数也通过同一入口执行；`result.txt` 只代表应用内的功能断言，最终结果以脚本退出码为准。

月视图和年概览均以圆角内容区边缘分隔内容，外围材质连续连接顶部和底部。毛玻璃开启或关闭时均不留下意外透出桌面颜色的分隔缝。普通冒烟另生成 `rounded-calendar-design.png`，固定为 2026 年 10 月 24 日、星期日起始，用于检查圆角设计及四字节日布局。

普通冒烟通过无障碍标签定位胶囊导航按钮并发送鼠标点击，检查前后切月、回到今天及上下边界禁用；同时生成 `navigation-*.png`，用于检查深色双位月份标题和禁用状态的布局。

视图快照用于检查文字与布局，无法完整呈现窗口服务器合成的后方背景模糊；冒烟额外生成毛玻璃关闭时的月视图、年概览及设置深浅色快照，以及重新开启后的月视图与年概览深浅色快照。毛玻璃透色和“减少透明度”的实际效果需在桌面上检查。

普通冒烟同时生成 `timeline-scroll-benchmark.json`，记录连续日期区 120 次、每次 24 pt 往返滚动的主线程同步处理耗时；此记录不代表屏幕帧率，也不设置跨设备性能门槛。

运行脚本同时拒绝 SwiftUI 布局循环和 AppKit 布局重入警告；即使应用功能退出码为零，出现这些诊断也视为失败。

## 系统日历日程

当天日程展开提供独立专项：

```sh
python3 scripts/run-smoke.py "$PWD/build/agenda-smoke" --calendar-agenda-smoke
```

该检查先生成 `first-week-geometry.json` 和 `first-week-{detailed,compact,dots}-{light,dark}-expanded.png`，通过真实周行检查周日／周一起始的四至六周月份、四种日程模式及深浅色：首周选中灰底的周内顶部位置精确为 6.5 pt（转换到屏幕坐标允许原生表格与视口取整造成的一个物理像素误差）、整月高度不变、日期和标记不越过分隔线、首周展开保持日期原位及详情上方 8 pt／下方 6 pt 间距。旧均分居中实现须在首周顶部间距断言失败。随后通过生产日期按钮、原生周行和展示控制器，覆盖首次选择、再次展开／收起、展开动画与端点的窗口／可视区尺寸不变、底部详情固定、后续周行下移与收起归位、月末日程通过滚动日历完整可见、切日重置、12 项日程的内部滚动与到底提示、固定剩余数量提示、少量自适应和空状态、深浅色、周日／周一起始、月末跨日日程、快速反向、减少动态效果、设置与年概览返回、月份导航和 Esc 分层收起。导航回归通过真实“今天”按钮覆盖一月一日、今天和当月其他日期展开后滚动到邻月，再返回今天：记录 `agenda-navigation.json` 中的中间滚动位置，要求原详情保留且没有淡入过渡；选中日期与展开日期不同时，点击选中日期可切换详情。另覆盖从 2027 年 3 月返回 2026 年 11 月，先确认原日期离开查询范围，再要求一次点击到达目标；返回末段详情可见时注入事件更新，要求更新已生效且导航未被取消、没有详情淡入。通过生产弹窗关闭／打开入口验证清空与默认收起。设置与年概览只暂时离开详情页面，不清除展开选择。挂起读取验证加载状态与隐藏后的迟到结果，另验证读取失败、隐藏时不访问权限或数据，以及展开时删除事件同步刷新。输出 `agenda.json`、`agenda-{light,dark}-{opening,expanded,scrolled}.png`、`agenda-last-week-{2,8}.png` 与 `result.txt`。`agenda-edge.json` 和 `agenda-edge-{light,dark}-{opening,closing}.png` 另覆盖十二月自由浏览，逐帧比较 13–19 日与 20–26 日的位移及绘制透明度，验证后者完全移出可视区及重新进入时持续平移且不淡出。`agenda-spacing.json` 与 `agenda-spacing-{light,dark}-{empty,one,two-other-day,overflow,span}.png` 检查整周零行、一行、两行、其他日期多项、溢出计数和跨日段，覆盖详细、精简、圆点模式下详情灰底距整周最后标记底边或空周选中日期背景底边 8 pt、日期位置与窗口尺寸不变、日期快照区域不与详情重叠、详情下方不残留回收的空白。`agenda-rows.json` 与 `agenda-rows-{light,dark}-{1,2,3}.png` 检查单行长标题、完整悬停文本及一至三项日程的分隔线像素，分隔线数量须为日程数量减一；实心字形样例检查标题正文与尾部透明度，确认右端渐隐。标题点击回归在深浅色下各对长短标题执行两次真实鼠标点击，确认进入系统文字选择状态、字体与完整文本不变；保留实时选择焦点并单独采集底层字段绘制，检查无重复字形，退出选择后与点击前逐像素比较，确认渐隐恢复。`agenda-title-{light,dark}-{long,short}-{selected-1,selected-2,restored}.png` 保留对应画面；原实现必须在底层重复绘制断言失败。长标题右侧渐隐、时间和来源日历名需人工检查截图；本专项不证明真实账户同步、物理触控板手感、旁白完整体验或不同显示器上的实际操作体验。

日程内容专项同时通过真实鼠标按下、延时松开检查日期背景反馈，记录 `day-feedback-{0,1}.json`（浅色、深色）的中间不透明度及实际绘制像素，保存恢复态和按压中间态图片。覆盖选中日期的渐变、快速反向、未选中日期松开与选中交接、减少动态效果和视图移除后的帧驱动停止。临时禁用插值时必须在“真实按下没有背景颜色中间态”断言失败；合成鼠标事件和像素取样不证明物理显示刷新率。

仅验证日程内容及其展开交互时，可使用 `--calendar-agenda-content-smoke` 运行上述内容检查（包括标题点击、渐隐、分隔线、固定窗口、内部滚动和边缘动画），不执行前置的跨月返回今天及弹窗重开导航检查。完整导航覆盖仍使用 `--calendar-agenda-smoke`，内容检查通过不能代替导航结果。

日程列表的鼠标位置与滚轮分发提供独立专项：

```sh
python3 scripts/run-smoke.py "$PWD/build/agenda-wheel-smoke" --calendar-agenda-wheel-smoke
```

该检查构造带窗口身份与实际视图坐标的滚轮事件，经应用分发到鼠标位置命中的视图，不直接调用指定滚动视图。覆盖普通滚轮、精确手势滚动、空列表、单条日程、多条日程及收起后重新展开；检查可见各周日期区域、顶部及侧边留白与正文。短列表正文应带动外层日历，多条日程应内部滚动且到底后不带动外层。输出 `agenda-wheel.json`，记录命中视图类型、内外层事件计数和位移。原实现必须在短列表正文无位移的断言失败。事件合成不替代物理设备驱动及实际惯性手感验证；月初吸附规则保持原样。

展开日程后的滚动性能提供独立专项：

```sh
python3 scripts/run-smoke.py "$PWD/build/agenda-performance-smoke" --calendar-agenda-performance-smoke
```

该检查通过生产日期按钮、真实周表格与隔离事件源，对 12 项和 200 项日程分别执行收起／展开状态的 120 次、每次 24 pt 跨月往返滚动。输出 `agenda-performance.json`，记录主线程滚动、布局与同步绘制的中位数、第 95 百分位、最大耗时，以及日程布局创建、周行配置、行高查询和动画准备次数。检查滚动不启动无关或离屏详情动画、仅创建内层视口附近的事件行且最后一项可达、未变化的数据复用布局、其他日期更新不重做当天详情、当天事件变化仍刷新布局和动画。临时恢复全量创建行时，该检查必须失败。耗时用于同机同配置比较，不设置跨设备阈值；异步等待期间的工作不全部计入同步样本，不代表屏幕帧率、真实账户同步或物理触控板手感。

切档启动与异步数据更新提供独立专项：

```sh
python3 scripts/run-smoke.py "$PWD/build/calendar-mode-latency-smoke" --calendar-mode-latency-smoke
```

该检查使用生产按钮 action（动作）启动，排除 `performClick` 自带的高亮等待；覆盖四至六周和深浅色，要求每次仅采集两个端点、日期底图按周采样且不生成整页 PDF、不额外截取整区位图（`fullBitmapCaptures` 为零）。挂起事件读取后先推进真实动画，再恢复跨日事件，检查未增加快照或整页准备次数，容器的位置、速度与时钟保持连续，标记实际展开；另检查切档途中进入年概览仍有日期缩放画布。输出 `mode-latency.json`，分别记录同步启动、平均端点采样、标记更新及总准备时间；其中 `markerRefreshWallMS` 包含异步恢复与采样等待，`markerRefreshMS` 仅测主线程标记更新。三个月份的同步启动和端点采样中位数须低于 20 ms；该本机调试预算不代表正式构建、系统授权等待、真实账户规模或物理屏幕帧率。

四档正文缩放动画提供独立专项，不运行全流程：

```sh
python3 scripts/run-smoke.py "$PWD/build/calendar-mode-animation-smoke" --calendar-mode-animation-smoke
```

该检查在点击前安装真实布局观察器，从布局准备、逐帧运动到交接结束比较整块页眉的屏幕坐标，生成 `header-position-{月份}-{模式}.json`；`header-position-rapid.json` 和 `header-position-live.json` 分别记录快速连点与真实刷新回调的顶部误差。旧实现的准备阶段会被此检查捕获到高度差一半的临时居中位移。检查通过生产按钮切档，使用真实视图的受控时间绘制生成 `mode-motion.json` 和起点、中间、终点快照，覆盖四至六周月份、深浅色与自由滚动位置、非线性高度变化、日期格连续绘制、面板顶部锚定、底栏跟随、连续切档的位置与速度接续、设置交接、导航及关闭取消和减少动态效果；接续误差在重定向瞬间测量，允许新终点准备期间继续运动；另验证真实显示刷新回调能够完成并停止。像素检查比较切档前后未变化的页眉／底栏文字，检查相同事件结果不触发重复过渡，以及动画日期底图与真实日期视图的交接差异；`mode-retarget-pixels.json` 记录快速连点重定向瞬间的正文像素差。另以 `mode-static-pixels-{月份}.json` 记录同步冻结画面和减少动态效果终点与真实视图的像素误差（`frozenPixelError`、`targetPixelError`），四档均须小于 0.1；`mode-static-{月份}-{模式}.png` 保存静态终点。其余误差记录为 `headerPixelError`、`footerPixelError`、`handoffPixelError`，采用预乘透明度的 RGBA（红绿蓝及透明度）通道平均绝对差，数值范围为 0–255。快照和主线程几何采样不代表物理帧率、所有显示器刷新率或真实触控板手感。

python3 scripts/run-smoke.py "$PWD/build/calendar-mode-smoke" --calendar-mode-smoke

该检查通过真实按钮依次点击四档，生成 `mode-cycle-{模式}.png`；使用隔离事件库验证隐藏状态下切月和后台通知不检测权限，恢复三种非隐藏模式时自动检测并申请尚未决定／仅写权限，完整权限不重复申请，拒绝／受限提供设置提示，快速连点复用授权，以及隐藏后迟到读取不再检测权限或恢复事件；另验证相同结果和相同空结果不重复发布更新，真实的事件修改与移除仍会发布。它不验证完整日历导航、页面过渡、真实系统授权窗或账户同步。


```sh
python3 scripts/run-smoke.py "$PWD/build/calendar-events-smoke" --calendar-events-smoke
```

该检查通过生产图标按钮按顺序循环切换到四档模式，使用真实控制器、日期索引、日期按钮和面板生成 `events-{月份}-{模式}-{外观}.png`、`events-geometry.json` 与 `result.txt`。覆盖默认隐藏不读取、不请求授权，授权拒绝、系统限制、仅写权限、重复授权请求合并、偏好持久化、读取失败与重试、跨日事件、隐藏后的迟到结果、读取期间权限撤销，以及后台线程的事件库变更通知。

二月、八月和十一月分别覆盖四至六周月份，选中跨日事件中的 18 日；十月额外选中 6 日，同时展示跨日假期与单日事件。在每种模式与深浅色下检查面板仍宽 320 pt、选择保留、图标处于月份与“今天”之间、日期反馈底色不延伸到日程区域、日程与底色至少间隔 3 pt 且底部不被日期格裁切，并检查隐藏模式不在日期旁白标签中保留事件标题。九天的跨周示例覆盖详细胶囊和精简横线，检查同周内各日期共享横条几何位置，直接采集日期列接缝的蓝色像素，并比较长短周段的底色防止重复叠绘，`events-geometry.json` 的 `spanSeams` 记录接缝采样数；另生成设置及年概览快照。普通冒烟包含同一检查，后续继续验证原有导航、滚动和页面过渡。

仅系统权限与事件库边界使用隔离数据，不弹系统授权窗、不读取真实用户日历、不修改系统权限或日程。真实授权需从完整 `DayOrder.app` 主动选择非隐藏模式，分别检查允许及拒绝后从系统设置恢复，并在系统日历修改事件后确认面板刷新；该人工步骤和账户同步不由隔离回归证明。日期归属的单元测试另覆盖设备时区、夏令时、午夜排他结束、全天排序、重复实例和无效事件区间；周排布测试覆盖跨周、跨月、周起始日、同名不同实例、重叠分行与溢出时整段让位。

日程专项还在二月、八月、九月示例中对比真实日期按钮的直接绘制与 PDF 快照回放，检查长短标题没有黑块且保留文字像素；图标必须同时保留白色线条和透出圆底的镂空，按最多一个回放像素对齐后，回放与原图的 RGB 通道平均绝对误差须小于 0.08（通道范围 0–1），避免退化为白色实心块。通过真实月年页面和受控时间采样双向缩放，覆盖深浅色的起点、中间帧、终点及返回后的月历。各月份的输出保存在 `zoom-{月份}/`，包含 `event-zoom-pixels.json`（含 `iconPixelError`）与 `event-zoom-{外观}-{live,returned,out-帧号,in-帧号}.png`。末日设为今天并添加日程，动画末帧的日期数须等于历法给出的本月天数；`before-handoff` 与 `returned` 快照对比最后一周，`lastWeekHandoffError` 记录交接前后的 RGB 平均绝对差，须小于 5（通道范围 0–255），防止最后一周在交接后才出现。该检查验证事件绘制与月年画布的组合，不代表物理帧率或所有显示器缩放比例；完整月年交互与刷新驱动仍由[月年缩放过渡](#月年缩放过渡)专项覆盖。
