# Agent Note: Calendar Text Contrast

Status: proposed

## Problem

卡片提亮后，农历、星期和底部详情仍偏淡；本月周末与邻月补位日期同时弱化，增加扫读负担。

## Proposal

本月日期统一使用主文字色，保留今天红圈与白字；缩放锚点使用相同颜色，避免动画交接时周末重新变灰。CalendarSurface 唯一拥有辅助文字与邻月文字的深浅色灰阶，月视图农历、月年星期栏、底部详情和年概览底部提示复用辅助文字色，邻月日期数字、农历、节日及休班标记共用同一弱化颜色：浅色模式向白色靠近，深色模式向黑色靠近，统一表达月份归属。

深色模式辅助文字接近白色，邻月文字保留较弱层级；日程标题提高白色混合比例，保留少量日历色。浅色模式保留当前参数。深色邻月日程标题单独减少淡化，胶囊底色和图标仍沿用原透明度；标题继续受整体淡出和详情展开进度约束，避免转场中残留文字。

保留背景材质、阴影、字号、节日强调色和事件胶囊底色，不将此次文字调整扩大到设置控件或禁用态。邻月的弱化仍遵循[连续月历](../../implemented/feature/2026-10-24-continuous-calendar.md)的月份归属，具体颜色由代码拥有。

## Alternatives considered

- 继续提亮背景：辅助文字本身过淡时收益有限，且进一步削弱材质透色。
- 仅弱化邻月数字：下方农历和节日仍显得突出，月份归属表达不一致；合并为同一弱化颜色。
- 所有文字统一主文字色：容易阅读，但会失去日期、辅助信息和邻月之间的层级。

## Acceptance criteria

手动比较浅色和深色下的本月周末、农历、星期、底部详情、邻月日期及邻月日程标题，确认清晰且层级仍可区分；月年切换时日期颜色保持连续。试用阶段只构建和检查差异，不声称已完成对比度达标测试或完整界面验证。

## Risks

辅助文字比系统默认颜色更突出，可能改变视觉轻重；透色背景下的最终对比度仍需实机确认。邻月仍然较浅，尚未对所有背景组合测量可访问性对比度。
