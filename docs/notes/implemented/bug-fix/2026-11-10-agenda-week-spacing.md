# Agent Note: Agenda Week Spacing

Status: implemented

## Problem

整周均分高度并为日程模式预留最大标记高度，展开详情直接追加在周底时，无日程或只有一行胶囊的周留下大块空白。

## Decision

补充[当天日程展开](../feature/2026-11-10-inline-day-agenda.md)的周内布局决定。普通周仍采用原有均分高度；展开周保留日期数字原位置，按整周实际绘制标记的最末底边放置详情，至少容纳日期与农历区域。复用标记几何，计入跨日分行和溢出计数，不用所选日的事件数量推断整周占用。详情背景与最后一行标记间隔 8 pt（视图前置 4 pt 加背景内缩 4 pt）。周高只增加详情扣除回收空白后的净高度，避免把空白搬到卡片下方。

日期按钮同步裁去未使用的底部区域，避免周位图裁切时把上移后的详情重复纳入日期动画。协调器缓存展开周的内容底边，仅在日期选择、周起始日、显示模式或事件修订变化时重算，不在滚动行高查询中创建标记。事件补回引起的周高变化仍遵循既有导航连续性约定。

## Alternatives considered

- 只向上移动卡片而保留周总高度：卡片下方仍有无用途留白，日期按钮快照还可能包含卡片内容。
- 按所选日数量压缩：会覆盖同周其他日期的第二行，且不能正确表达跨日分行与溢出计数。
- 所有周改为内容驱动行高：会改变普通月份的网格及导航几何，超出此次展开间距需求。

## Consequences

同周其他日期的事件变化也可能改变展开周高度，必须刷新该周行高；普通滚动继续复用已计算的高度与详情布局。真实日程专项覆盖零行、一行、两行、同周其他日期、跨日及溢出场景，并检查固定窗口、日期原位和下方周行平移；滚轮、导航和滚动性能专项继续约束原交互。临时恢复在基础周高之后追加详情的旧布局时，零行场景的间距断言必须失败，防止检查只验证卡片存在而遗漏大空白。快照只证明隔离数据下的界面结果，不代表真实账户同步或物理设备手感。
