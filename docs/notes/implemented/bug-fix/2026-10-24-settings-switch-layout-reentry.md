# Agent Note: Settings Switch Layout Reentry

Status: implemented

## Problem

设置、菜单栏偏好、弹窗重开与材质切换连续执行时，功能断言可全部通过，但仍输出 AttributeGraph 布局循环诊断。调用栈显示 SwiftUI 正在执行 Switch.updateNSView，原生 NSSwitch 的隐式状态动画通过 displayIfNeeded 同步触发窗口布局，再次进入尚未完成的 SwiftUI 属性图更新。

## Decision

只对设置中的原生 Toggle 禁用绑定同步事务的隐式动画。状态仍由原有绑定驱动，保留 NSSwitch 的原生外观、交互与辅助功能语义；页面容器、日期缩放和显示刷新驱动不受该事务影响。不屏蔽系统诊断，也不以重建整个设置页避开控件更新。

冒烟的合成输入阶段固定弹窗，防止测试宿主抢走焦点造成点击或中间帧采样失败。尾部无合成输入的偏好与材质场景恢复生产临时弹窗行为；仅将所有测试永久固定为 applicationDefined 虽能避开已知触发条件，却不能作为控件修复的证据。

通过 run-smoke.py 统一检查真实应用的退出码与运行日志。保留完整 runtime.log，出现 AttributeGraph 布局循环即失败，即使应用内功能断言已写出成功结果。脚本设置进程超时，超时终止并等待该测试进程；不修改用户日常偏好或长期运行的应用实例。

此决定补充[设置容器过渡](../feature/2026-10-24-settings-container-transition.md)的外观更新时序与[统一设置页面](../feature/2026-10-24-rounded-settings-surface.md)的原生控件选择。外观任务仍避免同步更新窗口外观；开关布局重入由控件自身的事务边界处理。

## Alternatives considered

- 只增加等待或固定所有测试窗口：可改变复现概率，不能移除原生开关在布局中的同步动画调用。
- 禁用整页动画：会扩大到已经确认的设置往返及月年过渡，超出问题所在边界。
- 自绘开关或重新封装 NSSwitch：增加绑定、键盘和辅助功能维护；公开的 SwiftUI 事务已能限制这条重入路径。
- 忽略框架警告：功能断言无法证明布局没有重入，需要将日志纳入检查结果。

## Consequences

设置控件的程序化状态同步直接到达目标状态，避免更新期间的隐式窗口重绘。原生控件的交互与持久化语义不变；页面过渡继续按原有驱动执行。

已知场景在修复前产生 18 条循环诊断，修复后使用相同临时弹窗行为验证。日志检查以该真实失败日志作为负向控制，确保不能仅靠功能断言判绿。覆盖限于实际运行的 macOS 版本和场景，不推断其他系统版本不存在框架布局问题。
