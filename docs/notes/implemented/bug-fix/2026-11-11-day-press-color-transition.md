# Agent Note: Day Press Color Transition

Status: implemented

## Problem

日期正常选中底色与按压反馈直接切换，快速按下、松开会产生明暗跳变。取消按压反馈会损失操作确认，用户希望保留反馈并平滑过渡。

## Decision

日期按钮拥有短时的不透明度插值，在实际绘制入口读取原生高亮状态，避免另建鼠标命中、拖出取消或动作派发逻辑。[共享日程背景](../feature/2026-11-11-agenda-soft-surface.md)继续拥有正常选中颜色，按压时长与强度由[日历参考](../../../calendar-reference.md#系统日历日程)拥有。快速反向和松开后的选中更新从最后显示颜色接续，不先归零；插值使用无过冲的三次缓出曲线，先快速响应，再柔和收敛，避免缓慢起步产生拖拉感。

复用现有 `CalendarDisplayLinkTarget`，仅在过渡期间注册公共运行循环模式，让原生鼠标跟踪期间也能刷新。结束、隐藏、离屏、脱离窗口、日期身份改变和销毁时清理帧驱动；回调弱引用按钮。程序化选中和视图复用直接显示目标状态，系统减少动态效果时不启动插值。渐变只改变背景，不影响文字、日期操作、布局或日程详情底色。

## Alternatives considered

- 已选中日期始终保持同一底色：消除跳变，但也移除了用户希望保留的按压反馈。
- 单独接管鼠标按下和松开：需要重新维护拖动取消与原生操作语义；读取实际绘制时的高亮状态即可覆盖原生跟踪。
- 每次状态变化从固定端点开始：快速反向或松开与选中交接会再次产生颜色跳变。

## Consequences

真实生产日期按钮在独立窗口接收原生鼠标事件，深浅色下取样中间不透明度及背景像素，并验证动作只派发一次、反向连续、减少动态效果和移除后停止刷新。原来的立即切换路径必须被中间态断言拒绝。日程内容专项继续覆盖真实月历展开和收起；合成事件不替代物理鼠标手感及完整屏幕帧序验证。
