# Agent Note: Remove Date Tooltip

Status: implemented

## Problem

鼠标停留在月视图日期上时，完整日期、农历和假期信息弹出为长条悬浮提示，遮挡附近日期；用户要求移除。

## Decision

移除日期按钮的原生悬浮提示，完整信息继续通过点击后的底部详情和无障碍标签提供。此决定部分取代[世界日名称展示](../feature/2026-10-23-world-day-labels.md)中的悬停提示用途，保留短名与完整名称的分工。

## Alternatives considered

- 缩短悬浮文字：仍会在浏览日期时弹出遮挡内容，不符合取消提示的需求。

## Consequences

日期绘制、选择和无障碍标签保持原样，导航、设置及菜单栏的操作提示不受影响。现有界面冒烟覆盖日期选择和详情；静态视图快照不证明真实鼠标停留时的系统提示行为。
