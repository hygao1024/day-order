# Agent Note: Stable Calendar Mode Rendering

Status: implemented

## Problem

日程切档复用整页切换时，上下栏中没有变化的文字也在旧快照与真实视图之间淡化。普通透明度叠加会让相同文字中途变浅，透明度之和等于一不能证明像素亮度保持不变。每次查询又无条件发布事件更新，可能在同一次切档中重复准备布局和重置时间进度。日期底图从局部坐标采样后按带小数的格宽绘制，还会改变位图的像素相位，在交回真实视图时产生细微跳感。

## Decision

部分取代[四档正文缩放](../feature/2026-11-06-calendar-mode-animation.md)的整页交接：日程切档保留真实页眉与底栏，不生成它们的文字快照；底栏仍随正文下沿移动。设置和月年切换继续使用原来的交叉淡化，不改变页面导航布局。

系统日历控制器仍在每次非隐藏模式切换时检查权限并读取事件，但仅在完整日期索引发生变化时发布事件更新。隐藏、权限撤销、失败和真实事件修改或移除仍由原有代际与清空路径处理；不通过少检测权限来减少刷新。

日期底图按根视图的实际像素网格对齐采样区域，在所属周行内采集，保留格内偏移与原始尺寸。绘制只移动到相同像素网格，不把取整后的位图再次缩放到带小数的格宽；连续切档的合成底图遵循同一约定。采集范围限制在周行，避免把仍处于运动起点的底栏录入日期底图。标记继续由[日程连续形变](../feature/2026-11-06-calendar-marker-morph.md)独立绘制，值与速度接续不变。

顶部在布局准备期间的空间锚定与窗口尺寸交接由[顶部锚定修复](2026-11-06-calendar-header-anchor.md)补充；本文继续拥有亮度混合、事件更新去重和日期底图采样的理由。

## Alternatives considered

- 调整弹簧时长掩盖闪动：不会消除文字透明度下降、重复准备或位图再次采样。
- 对未变化的上下栏改用另一种混合算法：增加无必要的合成工作；日程切档只需要更新图标和移动底栏。
- 切档时跳过权限检测或停止刷新日程：会改变已授权的权限与数据更新契约。
- 按整张根视图采集每个日期区域：可能包含覆盖在旧位置的底栏，采集所有者必须限定为日期所在周行。

## Consequences

四档终态、胶囊形变、滚动位置与原有布局不变。专项使用真实组合视图比较上下栏文字亮度及动画／真实日期视图交接像素，覆盖四至六周、深浅色、连续切档和页面交接；另验证相同事件结果不重复发布、真实修改与移除仍可见。隔离副本恢复上下栏淡化、无条件发布更新或局部坐标采样时，检查必须失败。不运行全流程；像素证据与显示驱动收敛仍不能代替物理屏幕帧率和实机操作体验。
