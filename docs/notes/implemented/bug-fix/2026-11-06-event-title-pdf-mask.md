# Agent Note: Event Detail PDF Rendering

Status: implemented

## Problem

长日程标题使用 destinationIn（透明度遮罩混合）实现尾部渐隐，直接绘制正常，但月年画布的 PDF 快照回放会把黑色渐变绘成实色矩形。短标题不进入该分支，所以只在部分事件中出现黑块。

同一路径还会丢失系统日历符号的内部镂空，表现为彩色圆底上的白色实心块；仅修复文字遮罩无法修复图标。

## Decision

需要渐隐的标题和系统日历符号分别在透明位图内完成合成，再以普通透明图片绘入事件区域。两者复用局部位图绘制方法，不将彩色圆底或整条胶囊扁平化。短标题继续原生绘字，胶囊背景仍按矢量绘制。位图使用当前绘制变换对应的分辨率、至少两倍采样；当前图形上下文在退出时恢复。分配失败时文字退回裁切，图标仅保留圆底，不向 PDF 输出不兼容的遮罩或符号。

此决定细化[标记形变](../feature/2026-11-06-calendar-marker-morph.md)的共用绘制器：静态日期、形变和月年快照使用同一标题与图标外观。保留[月年画布](../feature/2026-10-24-calendar-canvas-zoom.md)的 PDF 来源和预绘制策略，不将整个日历改成低分辨率截图，也不增加持久缓存或事件数据副本。

## Alternatives considered

- 关闭长标题渐隐：可以消除黑块，但改变已有的标题截断外观。
- 将整个月年画布替换为位图：扩大缩放与文字清晰度的影响面，故只在不兼容的文字遮罩边界完成位图合成。

## Consequences

长标题与图标绘制会临时分配小位图，需通过切档性能与形变专项检查成本；短标题文字不增加位图分配。日程专项增加真实日期按钮的 PDF 回放、文字像素和图标镂空检查，并覆盖深浅色双向月年缩放的实际中间帧。旧文字绘制器应在 PDF 黑块断言失败；保留文字修复、恢复旧图标绘制器时应在图标像素误差断言失败，恢复后分别复验。图标检查同时要求正常绘制保留白色线条与彩色镂空，防止两端同时画成白块而误判一致。视图快照不能证明所有屏幕比例、物理帧率或系统版本的表现。
