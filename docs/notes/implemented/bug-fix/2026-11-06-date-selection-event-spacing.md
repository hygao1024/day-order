# Agent Note: Date Selection and Event Spacing

Status: implemented

## Problem

显示日程时日期按钮随行高增长，选中底色也覆盖整格，导致灰色选中态与跨日横条、单日胶囊叠在一起。农历与事件距离过近，日期和日程缺少清晰分区。

## Decision

保留[日期圆角选择](../feature/2026-10-29-rounded-date-selection.md)的两行日期语义，选中、按下与焦点共用固定日期范围。日期按钮仍拥有整个日期格的命中、旁白与绘制，不为视觉分区新增交互层。

所有非隐藏模式的事件下移 4 pt，日期格相应增加 4 pt，继续按六周容量推导日期区高度，避免六周月份的末行胶囊与溢出计数被裁掉。隐藏模式保持原尺寸。该决定部分取代[跨日连续展示](../feature/2026-11-06-continuous-calendar-events.md)中保持行高的约束；横条仍使用同周固定行，动画沿用真实日期底图和事件端点。

## Alternatives considered

- 只缩短底色：消除叠色，但事件仍紧贴农历，无法形成足够留白。
- 只下移事件、不增加日期格与视口高度：六周月份的第二行胶囊会被裁切。

## Consequences

非隐藏模式的面板比原来高 24 pt，换取稳定分区并保留事件容量。真实日程专项覆盖四至六周、深浅色和十月六日的单日／跨日混合场景；几何检查要求底色止于日期区域、事件与底色保持间距且底部完整。旧实现会在底色范围检查失败。静态快照用于人工检查实际叠色与留白，模式动画专项覆盖不同高度端点的交接；不证明所有显示器或真实账户同步。
