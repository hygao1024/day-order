# Agent Note: Single Calendar Date Grid

Status: implemented

## Problem

整张画布缩放在后段交叉淡化两份完整日历。年视图日期行距与月视图不成等比例，即使相机位置、速度连续，同一天和今天红圈仍同时出现在两个位置，形成先放大、后换布局的视觉顿挫。逐帧重绘两张 PDF 也压缩高刷新率下的绘制余量。

## Decision

保留整张年画布的相机变换和邻月运动。焦点月份日期与红圈从两端正文快照中移除，在独立前景只绘制一次。所有日期使用同一个相机位置导出的布局进度，连续展开行距、字形和圆圈尺寸；没有逐日弹簧或单独的启动时刻。两端实际日期框拥有终点几何，避免在最后一帧再纠正舍入后的行距。

农历、节日、补位日期与分隔线通过同一行距展开映射进入，单独渐显。焦点月的原月份标题、星期字样随画布缩放，并在日期网格展开时提前淡出，避免与向上扩展的首周相撞。未共同可见的日期只在其可用端点渐显或渐隐；减少动态效果与无法建立焦点时继续使用完整正文短淡化。

月份反馈底色只属于正文画布。标题与星期的独立矢量快照复用原生文字绘制，但不包含悬停、按下底色和日期；否则按下时的半透明底色会在标题区域叠加两次，形成深色横块。截取模式仅在同步生成快照期间生效，并在返回前恢复，普通按钮反馈保持完整。

原生视图继续拥有字形样式和日常绘制。准备期间临时隐藏被接管的日期，完成快照后立即恢复。普通正文快照保持完整，缩放背景使用不含焦点日期的版本。背景在准备阶段按当前两端的最大显示尺寸和屏幕倍率预绘制一次，逐帧只合成；日期始终按当前字号原生绘制。缓存只属于当前转场，失败时可回退到矢量背景，不改变模型、滚动位置与偏好。

此决定部分取代[日历画布缩放](../feature/2026-10-24-calendar-canvas-zoom.md)中的完整正文交叉淡化与逐帧矢量背景绘制。相机、弹簧节奏、邻月整体运动、重定向位置和速度、外壳与清理责任继续适用。

## Alternatives considered

- 延长时长或调整淡化阈值：仍会同时展示两套错位日期，只改变重影持续时间。
- 给每个日期恢复独立弹簧：增加状态，并削弱整张画布的统一运动；共享布局进度即可承接相机反向。
- 全部正文非等比拉伸：日期和今天圆圈会变形；仅详情背景使用行距映射，日期字号与圆圈独立原生绘制。
- 每帧重绘全部矢量背景：清晰但成本偏高；按最大实际显示尺寸预绘制背景，避免放大小截图。
- 截取标题时临时取消悬停和按下状态：把快照内容与交互状态耦合；仅限制绘制内容即可保留按钮状态和矢量文字。

## Consequences

相机与布局进度共享状态，中途反向不重新启动网格展开。图像缓存增加短期内存和准备工作，换取更低的逐帧绘制成本；转场完成或取消后释放。

回归检查绘制的日期份数、背景中今天红圈的残留像素和月端点位置误差。独立副本取消隐藏日期时必须因背景残留红圈失败。受控时间检查使用真实页面、准备路径与绘制层，覆盖四至六周、闰年二月、月中滚动返回、连续反向、设置插入与减少动态效果；它不证明显示刷新回调、物理帧率或实际操作手感，显示驱动仍由原有月年专项检查验证。

年概览检查同时验证深浅色、材质开关、悬停与按下状态的标题快照保留文字且边缘透明；旧的完整按钮截取会因包含反馈底色而失败。受控时间检查补充按下 2027 年 1 月按钮后的放大快照，检查实际合成效果。
