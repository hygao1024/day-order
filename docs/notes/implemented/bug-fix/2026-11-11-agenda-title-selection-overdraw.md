# Agent Note: Agenda Title Selection Rendering

Status: implemented

## Problem

[单行日程标题](../feature/2026-11-11-agenda-single-line-rows.md)使用自定义位图绘制渐隐，同时保留原生文本选择。点击长标题后，系统 field editor（文字编辑与选择层）绘制文本，底层仍绘制渐隐标题，两份字形轻微错位形成加粗和重影；字体本身未变化。

## Decision

以原生字段的当前文字选择层为绘制所有者：存在选择层时底层字段不再绘制文字，由系统选择层显示；不存在时按原规则绘制单行渐隐标题。不新增焦点标记、事件监听或缓存状态，避免状态与原生焦点生命周期不同步。保留文本选择、完整悬停提示和无障碍文本。

## Alternatives considered

- 禁止标题选择：能够绕开重复绘制，但会删除既有选择和复制能力。
- 调整字体粗细或文字透明度：不能消除两个绘制所有者，不同点击与焦点状态仍会产生重影。

## Consequences

选择期间的文本显示由系统拥有，结束选择后恢复原渐隐。真实日程专项通过原生鼠标事件，在深浅色下对长短标题反复点击，检查完整文本、字体、底层重复绘制与退出后的像素恢复；旧实现必须在长标题底层仍有文字的断言失败。保留各状态截图，范围不包含完整旁白、所有键盘扩选或第三方输入法行为。
