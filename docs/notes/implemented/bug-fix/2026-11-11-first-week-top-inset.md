# Agent Note: First Week Top Inset

Status: implemented

## Problem

周行均分整月高度并垂直居中日期内容，使首周选中背景到卡片顶部的留白随月份周数和日程模式变化，无法与左侧 6.5 pt 留白保持一致。六周月份直接下移内容会碰到分隔线。

## Decision

首周日期内容顶部固定为 6 pt，选中背景内收 0.5 pt 后得到 6.5 pt 可见间距。数字、农历、标记和选中反馈共用位置。首周高度取原均分高度与完整内容所需高度的较大值，包含下方分隔线；后续周均分剩余空间并按显示器像素边界分配，内容继续垂直居中，整月高度不变。

协调器统一提供周高与日期顶部位置，普通周绘制和展开行高使用同一来源，保持[日程周内间距](2026-11-10-agenda-week-spacing.md)的 8 pt／6 pt 约定。此决定部分取代[吸附布局稳定性](2026-10-24-calendar-snap-layout-stability.md)与[系统日历显示](../feature/2026-11-06-system-calendar-events.md)中的均分规则；同一月份在自由浏览和吸附时仍采用完全相同的几何，吸附只移动视口。

## Alternatives considered

- 只移动选中背景：背景与数字、农历和点击区域错位，不能表达整组日期的顶部留白。
- 所有周都固定顶部 6 pt：六周月份无法容纳完整内容，需要增高视口或裁切日期。
- 只在吸附后改变首周布局：重新引入吸附前后重排，与稳定浏览决定冲突。

## Consequences

六周月份的后续周比首周紧凑；四、五周通常只改变首周内容位置。真实界面检查覆盖两种星期起始、四至六周、四档显示、深浅色、首周详情展开和标记边界；旧实现作为负向控制在四周隐藏模式测得 13.25 pt 并触发 6.5 pt 断言。月初吸附与模式切换专项继续约束滚动和动画，快照不代替不同显示器上的人工体验。
