# Agent Note: Faster Settings Transition

Status: implemented

## Problem

设置往返采用 350 ms 感知时长的弹簧，并等待几何与速度接近静止后交还真实内容。较长的运动与收尾使频繁切换显得迟缓。

## Decision

将设置往返的弹簧感知时长缩短到 220 ms，继续使用无回弹模型、原有静止阈值及重定向时的位置和速度。缩短弹簧时长同时加快尾部收敛，不增加硬截止或放宽几何误差。正文和上下栏保持独立的 180 ms 淡化，减少动态效果保持 120 ms；月年缩放的独立节奏由[加快月年缩放](2026-10-29-faster-calendar-zoom.md)调整。

本决定部分取代[连续日历运动](2026-10-24-continuous-calendar-motion.md)中设置的 350 ms 节奏；快照、布局、取消、资源清理与连续反向仍由原机制负责。

## Alternatives considered

- 在 220 ms 强制结束：可能在容器仍有可见位移或速度时跳到终点，破坏快速反向的连续性。
- 同时缩短内容淡化：当前淡化已在主要运动结束前完成，先保留文字交接的可读性。

## Consequences

220 ms 表示主要运动节奏，不是点击到恢复交互的固定总时长；快照准备与自然收尾仍有额外耗时。设置专项检查约束普通往返在 220–280 ms 采样区间已完成至少 95% 的弹簧进度，且活动采样不超过 450 ms；继续覆盖往返高度、深浅色、材质、年概览入口、反向、关闭和减少动态效果。

时序采样与真实视图快照不能证明物理屏幕帧率或所有设备上的操作手感。
