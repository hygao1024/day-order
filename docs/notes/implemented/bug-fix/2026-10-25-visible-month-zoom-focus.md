# Agent Note: Visible Month Zoom Focus

Status: implemented

## Problem

自由滚动时，顶部月份由视口首行决定；它可能只剩最后一周，而下个月占据大部分画面。按顶部月份缩放会选错视觉焦点，也可能让行距求解只得到同一行日期。滚动位置异步记录，单独读取缓存还可能错过点击前的最后一次滚动。

## Decision

月视图进入年概览时，由当前原生列表在点击调用内同步读取视口。各行与视口相交面积按所属月份区块累加，标题和补位周计入其所属区块，不按补位日期重复计数。可见面积最大者成为焦点；面积相同取时间更晚的月份，因此跨年时也遵守同一规则。

列表同时取消待执行的吸附并记录当前周及偏移，避免先移动视口再开始缩放。模型只保存本次确定的焦点月份，年概览定位与动画两端快照共同消费它；顶部月份、选择与滚动位置不用于替换焦点。直接返回时沿用该月份并恢复原视口；选择具体月份时清除旧焦点，采用用户选择。连续反向期间列表暂未建立时，沿用已固定的焦点。

模型弱引用列表提供者，列表拆除时只解除属于自己的引用，避免旧页面清理影响新页面。点击时没有可用列表且没有已有焦点，才回退到模型月份。

相机参数接近目标并不保证实际日期框已接近目标，缩放误差还会被年画布坐标放大。转场结束同时要求相机与屏幕日期框收敛；回归在移除动画层的交接边界记录日期误差，不将异步轮询的最后一次采样误认为最后一帧。

此决定部分取代[日历画布缩放](../feature/2026-10-24-calendar-canvas-zoom.md)按当前月份确定缩放焦点的规则；整张画布、共享进度与日期单份绘制继续适用。

## Alternatives considered

- 按顶部标题或选中日期：它们表达浏览顶部与用户选择，不能代表当前画面占比。
- 统计可见日期数量：四至六周的行高不同，且边界日期可能只露出很小部分，不等于可见面积。
- 先吸附到完整月份：会改变当前滚动位置，在缩放前引入额外移动。
- 为所有月份引入独立动画：超出单一焦点选择需求；保留共享相机即可。

## Consequences

焦点可与顶部标题不同。只改变转场与年概览定位，不改变日期选择和自由浏览语义。真实入口回归覆盖双方占优、面积相同及其两侧、旧月份只剩最后一周、跨年、不同周数、星期起始、未等待滚动通知的点击、返回原位置和重新选月；逐帧检查实际画布的焦点月份。负向控制反转同面积的月份顺序，检查必须拒绝选择较早月份。
