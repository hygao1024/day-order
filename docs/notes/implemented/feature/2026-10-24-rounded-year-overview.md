# Agent Note: Rounded Year Overview

Status: implemented

## Problem

月视图采用内嵌圆角日期区后，年概览横向铺满的实色区与直线分隔不再与之协调。顶部按钮较重，月份间距也使跨年预览显得松散，但重新构建小月历会危及既有滚动表现。

## Decision

按确认的设计稿，将整个年概览滚动区置于单一圆角实色容器，外围共用系统弹窗材质；关闭毛玻璃时沿用实色替代。背景直接绘制圆角形状，固定正文容器与原生滚动容器使用同一圆角裁剪，保证滚动和外观切换时内容不会越过边界。

年概览隐藏原生纵向滚动条，避免滚动时覆盖右侧月份，与月视图保持一致；继续使用原生滚动容器处理滚轮和触控板输入。

把原有横向内部留白拆分为外边距和内边距，保留两列小月历的列宽及中间间隔。仅收紧月份行尾留白，保留完整六周日期的按钮高度和统一行高，使跨年定位仍由原生表格的确定几何负责。年份标题与月份标题对齐，继续使用不透明背景悬浮显示。

顶部使用简洁返回入口、独立居中标题与“今天”胶囊按钮；底部同时说明点击月份和滚动浏览的操作。月份保留整体按钮语义，仅悬停或按下时显示底色。月份内部留白与统一行高由[月份反馈留白](2026-10-24-month-feedback-spacing.md)进一步调整，取代本记录中保留日期列宽、只收紧行尾的选择。

此决定部分取代[年概览](2026-10-23-year-overview.md)的容器、导航和间距外观，以及[弹窗材质](2026-10-23-popover-material.md)的上下独立材质与直线边界；保留[原生小月历绘制](2026-10-23-year-overview-scroll-performance.md)的复用、缓存和悬停所有权。

## Alternatives considered

- 给每个月增加常驻圆角卡片：会把连续浏览拆成多个视觉块，设计稿只需要一个整体容器。
- 直接增加外边距并保留全部内边距：会压缩已有日期列宽，因此从原有留白中分配。
- 按每个月的实际周数调整行高：虽然能进一步压缩空间，但两列月份高度不同，也改变原有确定行几何；保留六周容量，只收紧行尾空白。

## Consequences

不改变年份输入范围、日期选择、星期起始偏好和 Esc 分层返回。原生列表继续复用月份行，圆角与材质仅位于固定容器，不引入逐日视图、依赖或后台任务。

年概览专项入口复用普通冒烟的交互验证，并覆盖设计日期、深浅色、毛玻璃开关、六周月份、悬浮年份与输入错误快照。视图快照不能证明实际桌面材质透色或物理触控板手感；其他系统版本与完整 VoiceOver 操作仍需人工覆盖。

月视图与年概览的容器尺寸和日期正文衔接由[日期缩放过渡](2026-10-24-calendar-zoom-transition.md)补充；静态布局与列表复用保持不变。
