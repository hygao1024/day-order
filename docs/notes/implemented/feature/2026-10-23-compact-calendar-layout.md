# Agent Note: Compact Calendar Layout

Status: implemented

## Problem

菜单栏日历的弹窗占用过多屏幕空间。今天的数字额外加粗，叠加白字红底后显得拥挤，与其他日期不协调。

## Decision

日期数字统一使用常规字重，今天继续通过红色圆底与白字标识。压缩弹窗宽度、单元格行高和留白；设置按钮移至日期详情标题旁，移除独占一行的底栏。保持日期单元格整个区域可点击，农历小字仅轻微缩小。

后续[分区与年概览设计](2026-10-23-year-overview.md)在保持宽度、字重和详情入口的基础上，为今天红圈增加行内留白，并采用三段底色与周行细线。

详情的辅助功能分组保留内部控件，避免新增到标题行的设置按钮被合并进纯文本标签。月份行数仍由日期网格决定，六行月份不裁剪内容。

## Alternatives considered

- 整体等比缩放：可以直接减小面积，但农历、节日和按钮也会变得过小。
- 只修改今天的字重：能改善数字协调性，但不能解决弹窗尺寸问题。

## Consequences

继续使用现有真实弹窗快照检查浅色、深色、六行月份、节日重合和设置界面。尺寸与位置的当前契约由界面代码及 README 拥有；日期行为保持原样。
