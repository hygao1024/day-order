# Agent Note: Observance Summaries

Status: implemented

## Problem

日期详情已有农历、节日名称与放假安排，但用户还希望就地了解每个节日的简短含义；所给示例为霜降，因此范围也包括节气。

## Decision

在现有 Annotation 上提供内置的一句话说明，视图复用现有分类过滤后逐项展示。以完整名称匹配说明，清明节的民俗含义与清明节气的时令含义各自表达。说明与 holiday-cn 的年度放假事实分开维护；文本不推导是否休假，也不承担气象预报职责。

沿用 320 pt 宽度和次要文字样式，在农历与休班信息下方自然换行。普通日期不保留说明区；多项重合允许详情适度增高，以免省略用户希望看到的其他节日。

## Alternatives considered

- 联网查询节日百科：增加延迟和内容不确定性，一句话说明没有必要依赖网络。
- 只展示月历优先名称的说明：更节省高度，但同日其他已启用的节日会丢失。
- 新增独立卡片或详情页：增加视觉重量与操作，现有底部详情足以承载短文。

## Consequences

新增节日时应同步补充说明；核心测试遍历完整年份检查覆盖和长度。真实应用截图覆盖节气、节日、世界日、多项重合、开关隐藏、普通日期及深浅色。文字是内置常识性简介，不逐年追溯节日设立史；节气描述概括传统时令，各地实际气候不同。
