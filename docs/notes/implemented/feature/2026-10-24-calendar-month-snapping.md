# Agent Note: Calendar Month Snapping

Status: implemented

## Problem

连续日期区允许慢速浏览，但月初接近顶栏时，用户希望自动对齐并完整呈现该月。每次手势翻整月会破坏已经确认的连续滚动体验，扩大弹窗又不符合紧凑布局要求。

## Decision

在[连续日历](2026-10-24-continuous-calendar.md)的原生列表上增加整月状态，部分取代停止后永不吸附的决定。滚轮事件拥有手势和惯性阶段，原生滚动通知覆盖滚动条拖动；停止后防抖 220 ms，仅搜索顶部附近的月份边界。距离阈值与可见行为由 README 拥有。

吸附使用相同周行，完整呈现四至六周，不额外生成第二份月视图。顶部浏览月份同步更新，选择与详情保持原日期。最初在吸附开始时隐藏标题并切换行高，导致日期区先重排再滚动；该机制已由[吸附布局稳定性修复](../bug-fix/2026-10-24-calendar-snap-layout-stability.md)取代，采用始终一致的月份几何布局。

新手势取消等待或动画并释放吸附状态，保留当前滚动位置。普通明确导航清除恢复状态并展示目标整月；月视图“今天”的过渡由[返回今天动画](2026-10-24-animated-return-to-today.md)补充。返回设置按原状态恢复。任务使用取消和序号隔离，导航修订号、窗口可见性及视图状态阻止迟到吸附；拆除列表移除通知和回调。减少动态效果时直接对齐。

## Alternatives considered

- 所有停止位置都吸附：会把月中慢速阅读拉走，拒绝。
- 只平移至月初且保持固定周高：六周月份无法在现有高度完整显示，拒绝。
- 增大弹窗容纳六周：改变紧凑尺寸，拒绝；采用按月份周数分配的行高。
- 并排维护自由滚动和整月两份视图：需要同步选择、配色与恢复状态，当前可复用列表已经能够承载，未采用。

## Consequences

四至六周月份之间的行距不同，同一月份在自由浏览、吸附和解除吸附时行距保持一致。真实入口回归覆盖触摸和惯性等待、月中不吸附、动画被打断、导航与拆除取消、设置恢复、四至六周、日期边界与星期起始。快照入口暂停自动刷新定时器，避免较长回归中的固定日期被真实时钟覆盖，显式刷新检查仍保留。合成滚轮事件和视图快照不能证明物理触控板手感、窗口外点击关闭或所有 macOS 版本表现。
