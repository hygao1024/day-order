# Agent Note: Inline Day Agenda

Status: implemented

## Problem

日期格的胶囊和数量只提供日程概览，繁忙日期无法阅读全部标题。用户需要在当前月份上下文中，再次点击选中日期后查看当天全部日程，且不能让日期选中底色与事件混在一起，或因大量日程无限拉长窗口。

## Decision

`CalendarModel` 拥有一次性的展开选择，包含日期和所在月份区块。月份区块身份区分相邻月份重复的补位日期；只在实际点击的区块显示一份详情。周行拥有详情布局，在七列下方追加高度，不向核心时间线插入新行、不改变既有月份和周行索引。协调器只通知原、新详情所在周的高度变化，并沿用既有视口恢复保持日期位置；展开时保留实际小数偏移，即使月份标记为已吸附也不重新贴齐月首。

详情复用 `SystemCalendarEvents` 的当日投影，事件增加来源日历名；不另建查询、权限或持久化状态。列表全量呈现事件，按标题换行测量高度，少量自适应，多量限高并独立消费滚轮，包括边缘滚动。无溢出时的滚轮归属由[短日程列表滚轮传递](../bug-fix/2026-11-10-agenda-wheel-forwarding.md)部分取代，内容全部可见时交给外层日历。固定标题与剩余数量提供列表范围反馈。日历可视区保持当前显示档位的固定高度，详情仅增加周行高度，后续内容通过外层日历滚动查看；顶部导航、底部详情与窗口不随展开而移动或增高。列表限高独立于屏幕剩余空间，不再保存打开时的屏幕高度预算。列表不是日程编辑器。

展开、收起与切日扩展[日程布局动画](2026-11-06-calendar-mode-animation.md)，由原展示控制器统一拥有端点、取消和减少动态效果；展开仅移动日历内部单元，外壳尺寸不变。固定视口下，展开会把仍存在的周行推到屏幕外。涉及详情的布局过渡在视口上下各追加最大详情高度的采样范围，让经过可视边缘的周行同时拥有真实起止位置和图像；运动保持不透明，最终由卡片圆角裁切。收起沿用同一范围，避免重新进入的周行原地淡入。范围只增加当前过渡所需的有限周行，普通切档仍按原视口采样，不建立长期缓存。

详情图像从既有周行底图裁出，使用负标识避开日期和分隔线身份。关闭列表时清除事件子视图与回调；原先离开月视图、导航或关闭弹窗均清理模型状态；其中导航与页面交接的清理已由[会话内保留展开状态](../bug-fix/2026-11-10-agenda-navigation-retention.md)部分取代。关闭弹窗仍清理状态，晚到读取仍服从事件源既有代际边界。

[切档启动优化](../bug-fix/2026-11-06-calendar-mode-latency.md)的“数据返回仅刷新标记”在详情展开时不再充分：事件数量和标题会改变详情高度，因此最初在展开时统一重新准备布局端点。此刷新范围及布局复用策略由[日程滚动性能优化](../bug-fix/2026-11-10-agenda-scroll-performance.md)部分取代，仅当日事件实际变化且详情可见时重新准备；未展开时保留原低成本更新路径。

## Alternatives considered

- 只采集起止可见行，再对缺失单元淡出：视口外的周行仍然存在，缺少终点不代表删除；仅保持不透明也会留下原地停滞，必须保留真实屏幕外位置。
- 增大窗口容纳详情：会推动窗口底边和底部日期详情，违背固定窗口内展开的交互；即使按屏幕剩余空间压缩也不能解决此问题。
- 在每个日期格内无限扩展：列宽不足以阅读完整标题，大量日程使整周难以浏览。
- 新增独立表格行：需要改写核心周索引、导航、吸附与月年缩放的行身份，影响超出详情展示范围。
- 另开悬浮面板：不符合在所选周下面直接展开、保留月份上下文的交互。
- 展开详情时仍只更新日期标记：读取完成或事件删除后会留下过时列表和错误高度。

## Consequences

首次点击仍只选择，再次点击展开；展开后切换日期直接迁移列表。隐藏模式保持不读取日历的边界。读取中、无权限、失败与无日程有不同状态；来源日历名仅存于现有内存事件中。最初大量事件全部建立原生行视图，该选择已由[日程滚动性能优化](../bug-fix/2026-11-10-agenda-scroll-performance.md)取代，改为按内层视口创建事件行。月末详情可能初始位于可视区下方，用户需滚动日历查看；不自动移动当前周。

真实专项通过生产日期按钮和原生滚动验证固定窗口、周行位移与归位、月末详情可达性、内部滚动、异步结果、页面交接、快速反向、减少动态效果与 Esc；截图检查完整标题。共享切档性能与日程绘制专项继续约束原行为。临时禁用生产展开分支时，新专项必须因无法进入展开过渡而失败；恢复后再通过同一专项。十二月自由浏览的回归逐帧比较 13–19 日与 20–26 日的位移及绘制透明度，覆盖深浅色下展开后完全移出视口和收起后重新进入。旧的仅可见行采样在首帧即因远行停留原位失败。固定尺寸断言在仍增加窗口高度的旧实现上必须失败，证明检查能捕获违反固定窗口约定的行为。隔离数据不证明真实账户同步、物理帧率或旁白完整体验。
