# Agent Note: Civil Festival Labels

Status: implemented

## Problem

仅区分中国传统节日和西方节日，会遗漏元旦、劳动节等公历节日。用户需要这些日期的名称，不需要放假、调休或工作日判断。

## Decision

在现有日期注释中增加中国公历节日分类，沿用同一月历与详情投影，提供默认开启的独立开关。既有传统节日偏好保持原义，不把公历节日误归为农历传统节日。

重合时保留所有名称，月历延续传统节日优先，详情完整展示。名称使用现代固定日期，不推导假期范围或追溯历史设立时间。节日清单和展示契约由 README 拥有。

## Alternatives considered

- 合并进传统节日：改动较少，但混淆既有分类与设置含义。
- 引入年度假期数据：能够表达调休，但超出当前需求，并增加更新和联网责任。

## Consequences

现有用户无需修改偏好即可看到新增节日，关闭新开关只影响公历节日。节日同日重合通过日期测试及真实界面快照验证，不增加日程或假期数据模型。
