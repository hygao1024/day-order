# Agent Note: Grouped Settings

Status: implemented

## Problem

原设置页将所有控件纵向平铺，开关位置随文字长度变化，说明区占用大量空间。新增选项后页面会继续增高，与紧凑菜单栏工具的定位不符。

## Decision

设置视图按显示、日历内容和放假安排分组，行内采用左侧标签、右侧控件的统一对齐。沿用系统字体、原生开关和选择器，用语义颜色、轻量分隔线及分组背景建立层次，不引入新的视觉资源或主题系统。分组背景与控件外观现由[统一设置页面](2026-10-24-rounded-settings-surface.md)取代，分组、绑定所有权和固定操作入口的决定保留。

保留现有弹框宽度，中间选项区固定可视高度并支持滚动，返回和退出固定显示。来源和支持范围移入可展开的关于区域。设置视图通过绑定消费既有偏好，由 CalendarView 继续拥有偏好和即时刷新行为，不更改任何开关语义或存储键。

## Alternatives considered

- 只调整字体和间距：无法解决控件对齐以及内容持续增长的问题。
- 独立设置窗口：能提供更大空间，但增加窗口导航与生命周期，当前设置规模仍适合原弹框。
- 每个选项增加图标或彩色背景：增加视觉噪声；分组与对齐已能表达层级。

## Consequences

少用的信息需展开或滚动查看，主要操作保留固定位置。浅深色和不同显示模式通过现有真实弹框快照验证；既有菜单栏即时更新、年月跳转和重开归位验证继续运行。并行开发的假期功能保持原行为，仅纳入统一的设置行布局。
