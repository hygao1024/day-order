# Agent Note: Animated Return To Today

Status: implemented

## Problem

月视图点击“今天”直接替换滚动位置，用户无法感知当前浏览位置与今天所在月份的方向关系。要求快速滚回当月，同时保留连续日历、固定视口和已有吸附行为。

## Decision

月视图“今天”按钮提交带动画意图的导航修订；左右箭头后来由[月份导航动画](2026-10-29-animated-month-navigation.md)扩展。普通日期导航、Home、重新展开和年概览返回今天继续直接定位。模型保存目标与修订，原生日期区协调器拥有实际动画。到达当月首周后再更新选择与详情；途中顶部月份及恢复锚点跟随真实可见位置。

复用[月初吸附](2026-10-24-calendar-month-snapping.md)的单一任务、取消序号、导航修订检查与时间插值，不引入第二套滚动视图或行布局。返回今天与月份箭头统一采用三次减速曲线，快速起步后平滑收尾，不回弹；月初自动吸附保留原有缓入缓出曲线。返回今天比相邻月箭头保留更长的运动时间，让路径与减速收尾更容易看清；距离只影响有上限的动画时长，避免跨年返回耗时随月份数量增长；减少动态效果时直接对齐。已经对齐的日期区不做额外位移。

动画请求同时记录当时的选择，防止启动前发生的新选择被旧任务覆盖；新手势消费尚未处理的动画修订。新手势、日期选择、后续导航和视图拆除取消旧任务；每帧检查修订、当前界面和窗口可见性。返回今天期间不让迟到的停止通知启动普通吸附。重复点击从当前位置重新开始；中途进入设置或年概览后返回恢复实际位置，不重播已经消费的动画请求。

## Alternatives considered

- 对日期选择整体使用 SwiftUI 动画：实际位移由原生滚动视图管理，不能保证产生真实滚动或复用已有取消边界。
- 当时将所有月份导航都改为动画：超出返回今天的请求范围。后续明确要求的箭头动画由独立记录补充，重新展开等入口继续直接定位。
- 返回今天保留单独的缓入缓出曲线：虽然也是非线性，但起步明显慢于箭头切月，不符合两种导航手感一致的要求。
- 按固定速度逐月滚动：支持范围跨越两个世纪，远距离返回会耗时过长。
- 维护单独的返回今天动画任务：与自动吸附竞争同一滚动位置，增加取消和恢复状态，现有任务所有者足够承载。

## Consequences

选择与详情在动画期间保留原值，取消后不会被旧任务覆盖。顶部年份快速变化可能触发既有本地假期缓存读取，仍遵循原有任务取消策略，不增加网络请求。真实按钮回归记录中间位置并检查终点、双向与远距离、取消及恢复；旧直接定位实现在“缺少连续中间位置”检查失败，作为负向控制；未记录请求时选择的实现在启动前取消检查中失败。减速检查要求动画前段完成大部分位移，保留旧缓入缓出曲线时该断言失败，作为曲线统一的负向控制。位移采样不能证明窗口服务器帧率、全部系统版本或物理触控板手感。
