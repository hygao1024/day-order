# Agent Note: Month Feedback Spacing

Status: implemented

## Problem

年概览月份的反馈底色紧贴标题左上边缘，六周月份底部也缺少留白。仅调整背景圆角无法改善内容与边界的关系。

## Decision

两列月份均为标题和日期网格保留 8 pt（逻辑点）内边距，悬停与按下背景、键盘焦点轮廓使用 8 pt 圆角。浅色悬停采用 `#F5F5F5`，深色使用略亮于内容区的底色；按下继续加深反馈，不引入投影或常驻选中状态。

月份按钮统一高 138 pt，月份行统一高 144 pt，为原有六周日期排布增加上下留白。年份标题与月份标题对齐。日期日常绘制与月年缩放端点继续共用日期坐标，避免内边距造成过渡错位。

此决定部分取代[年概览圆角设计](2026-10-24-rounded-year-overview.md)中保留原日期列宽、收紧行尾的间距选择；保留其外层容器、导航、列表复用和整体按钮语义。

## Alternatives considered

- 仅修改圆角：仍留下标题贴边和六周日期贴底的问题。
- 保持原行高并在内部挤入留白：需要压缩字号或日期行距，降低小月历可读性。
- 根据实际周数收缩反馈背景：切换月份时背景高度不同，不利于两列统一排列。

## Consequences

固定弹窗内可同时看到的月份内容略少，日期列略窄；日期字号、六周容量及整月点击区域保持可用。年概览真实入口生成浅深色、材质开关及六周月份的悬停与按下快照，月年缩放专项入口检查调整后的日期端点。视图快照仍不覆盖窗口服务器材质合成、完整 VoiceOver（旁白）操作或所有系统版本。
