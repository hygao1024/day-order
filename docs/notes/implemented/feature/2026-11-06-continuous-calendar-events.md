# Agent Note: Continuous Calendar Events

Status: implemented

## Problem

同一跨日实例在每个日期格独立绘制胶囊，重复标题且无法表达持续范围。只消除格子之间的间隙仍会因每日排序不同而错行，也会在末行出现溢出计数时从中间断开。

## Decision

周排布复用现有日期索引，不重新解释设备时区、午夜排他结束或重复事件。身份使用事件标识与实例开始时间；名称不作为合并依据。跨日段优先占用完整周段的固定行，单日日程复用空位。详细模式计数与末行段冲突时，整段让位并计入覆盖各日的未展开数量，以有限高度换取横条不被局部打断。

各日期按钮显式裁切同一个周段矩形，而不增加覆盖七列的交互视图；不依赖 AppKit 隐式裁切，避免透明背景随列数重复叠绘而加深。这样标题可连续跨列，只在周段开头出现一次；真实端点圆角，跨周延续端平直，补位日期仍按日期格淡化。精简横线共享同一排布，圆点保持逐日表达。日期点击、键盘焦点、旁白、截图采集和模式动画继续由原有日期按钮拥有。收拢点留在各日期格内，避免长段中心位于格外时圆点消失。

本记录部分取代[系统日程](2026-11-06-system-calendar-events.md)的逐日独立排布，以及[标记形变](2026-11-06-calendar-marker-morph.md)的静态布局不变约束；权限、数据索引和动画生命周期仍由原记录拥有。

## Alternatives considered

- 每天画相同名称并去除内侧圆角：没有周内固定行，重叠和溢出仍会使横条断开，也无法让标题跨越日期列。
- 在周行新增覆盖七列的独立日程层：需要迁移日期命中、截图排除和形变身份；按格裁切共享周段即可复用现有所有者。
- 仅拥挤当天用计数替换横条：会使同一实例在周内出现缺口，破坏持续范围表达。

## Consequences

保留现有面板宽度、行高和两行／三行容量，不增加依赖。整段让位与固定行可能使某些日期有空位或只有计数，完整标题和实际数量仍在日期旁白中。跨周重新分配行，不要求不同周的垂直行号相同。

单元测试覆盖身份、跨周跨月、排他结束、重叠和溢出。真实应用日程专项覆盖深浅色及四至六周月份，采集跨列接缝像素，并从完整面板快照比较长短周段的底色；局部重绘的裁切会掩盖向外叠绘，不能代替完整面板证据。临时将日期格两侧各裁掉 1 pt 时，专项因接缝缺少实际着色像素失败；临时移除显式裁切时，专项因长短周段底色不一致失败，恢复后复验。标记形变专项使用跨日实例覆盖模式切换。日程专项的同档位重试也通过真实按钮完整循环触发刷新，避免测试助手因模式未变而不执行重试。隔离事件库与视图快照不证明真实账户同步、系统授权窗或物理帧率。
