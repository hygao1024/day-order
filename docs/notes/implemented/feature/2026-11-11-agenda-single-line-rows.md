# Agent Note: Single Line Agenda Rows

Status: implemented

## Problem

长日程标题换行后使各行高度不一致；每项底部都绘制分隔线，导致单项和最后一项下方出现多余横线。用户要求标题单行渐隐、只在相邻日程之间显示分隔线。

## Decision

部分取代[当天日程展开](2026-11-10-inline-day-agenda.md)的换行测量决定。日程采用固定行高，标题单行，来源日历名仍占下一行；长标题复用事件胶囊的透明位图渐隐绘制，保留完整字段文本与悬停提示。渐隐在位图内完成，避免动画快照回放透明遮罩时出现黑块。胶囊沿用原渐隐宽度，详情标题使用更宽的渐隐区。

分隔线归属前一项，按完整事件数组的索引判断是否存在下一项，不按当前创建的视图数判断。虚拟化只创建视口附近行时，中间项仍有分隔线，最后一项始终没有。布局缓存及滚轮归属沿用[滚动性能优化](../bug-fix/2026-11-10-agenda-scroll-performance.md)和既有短列表传递规则。

## Alternatives considered

- 使用省略号截断：用户要求尾部渐隐，且已有可复用的位图绘制方式。
- 保留按标题测量的行高但只显示一行：会留下看不见内容所占的空白。
- 隐藏当前已创建视图中最后一行的分隔线：滚动虚拟化时会把列表中间行误当成末项。

## Consequences

单项无分隔线，两个和三个日程分别有一条、两条；数据增删会重建当前事件行并更新末项身份。真实专项覆盖深浅色长标题、一至三项分隔线像素和动态刷新，临时恢复末项分隔线时，单项像素断言必须失败。原多项滚动及导航检查继续约束固定窗口与末项可达性；截图检查渐隐和来源名称。完整标题保留在原生文本字段与悬停提示中。[标题选择绘制](../bug-fix/2026-11-11-agenda-title-selection-overdraw.md)补充系统选择层与渐隐层的互斥规则及点击回归；完整旁白与键盘扩选仍未由此证明。
