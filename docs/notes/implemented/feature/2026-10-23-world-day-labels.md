# Agent Note: World Day Labels

Status: implemented

## Problem

用户需要世界艾滋病日等国际纪念日。此前节日分类缺少这类名称，而完整名称通常超出紧凑月历的单格宽度。

## Decision

沿用日期注释模型，新增默认开启的世界日分类和独立偏好，不改变已有节日开关的含义。只收录经官方来源核对的一组常见固定日期；完整清单、来源和排序由 README 拥有。

注释同时持有完整名称和短名，既有注释默认使用原名。月历消费短名，详情、悬停提示和无障碍标签消费完整名，维持现有 320 pt 宽度和字级。世界日与节气重合时保留两项，关闭世界日后正常回退到节气。

## Alternatives considered

- 合并进中国公历节日：无需新开关，但国际纪念日与已有分类含义不符，也无法独立隐藏。
- 加宽弹框或缩小字级：可以容纳全名，但违背紧凑且易读的既有设计要求。
- 接入在线纪念日目录：覆盖更多，但增加网络和更新责任；当前精选固定日期无需外部依赖。

## Consequences

已有用户默认可见新增纪念日，仍然离线运行。按现代日期逐年标注，不做历史设立年份考据或放假推断。新增条目应核对官方来源并提供可读短名；日期、同日重合通过核心测试，设置和完整名称布局通过生产弹窗快照检查。
