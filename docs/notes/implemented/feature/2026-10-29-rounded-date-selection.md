# Agent Note: Rounded Date Selection

Status: implemented

## Problem

月视图选中日期的紧小圆角与明显描边呈现输入框观感，与日期区和导航的柔和轮廓不协调。

## Decision

选中底块使用 9 pt 连续圆角和原有语义灰色填充，移除描边。日期与农历共用矩形底块，今天仍以日期数字后的红色圆形表达；两者保持不同语义。按下反馈与键盘焦点遮罩复用同一路径，避免交互时轮廓突变。保持原有单元格尺寸、留白、文字位置及命中范围。

此决定补充[月视图圆角日期区](2026-10-24-rounded-calendar-surface.md)的单日选择反馈，不改变外层容器和滚动布局。

## Alternatives considered

- 仅增大普通圆角、保留描边：仍具有表单输入框观感。
- 使用圆形或胶囊：两行日期内容需要稳定的矩形承载，过圆会弱化它与今天标记的区分。

## Consequences

日期选择通过浅灰填充表达，使用系统语义颜色适配深浅色。真实月视图快照同时展示选中日期和今天，覆盖毛玻璃开关及深浅色；四至六周布局沿用现有月视图冒烟验证。快照供人工检查视觉，不证明所有系统版本和辅助功能模式的效果。
