# Agent Note: Animated Month Navigation

Status: implemented

## Problem

月份箭头直接替换日期区位置，无法感知翻月过程。用户要求参考 Apple 的克制动效，使用非线性动画；连续日历已有纵向滚动、整月对齐与中断恢复，切月需要遵守同一空间关系。

## Decision

箭头复用[返回今天](2026-10-24-animated-return-to-today.md)与月初吸附的协调器、单一动画任务和导航修订。原生列表保持同一份日期与行高，使用三次减速曲线移动到目标月首周，不引入横向快照或第二份月历。日期选择继续在箭头操作时更新，顶部月份和恢复锚点跟随实际视口；返回今天仍在到达后更新选择。

模型另存正在请求的月份，仅作为快速连点的导航基准和边界判断依据。否则动画前半段仍可见旧月份，连续点击会丢失月份增量。完成、取消或拆除释放此基准；按修订匹配清理，避免旧任务清除新请求。新导航从当前实际位置重算剩余位移，反向保持位置连续，不保证速度连续。手势可消费尚未启动的请求，减少动态效果沿用直接对齐。

## Alternatives considered

- 横向滑动两份月历：与现有纵向时间轴形成两套方向关系，需要维护额外画布和切换后的恢复位置。
- 直接给 SwiftUI 按钮动作套动画：实际位移由 AppKit 列表拥有，不能保证改变原生视口。
- 为箭头新增独立弹簧驱动器：当前请求只需非线性减速；复用已有滚动所有者可以保留取消、选择与恢复语义，且避免两套驱动竞争。

## Consequences

箭头响应不会等待旧动画结束，连续操作可跨年且在支持范围边界停止。键盘切月和重新展开仍沿用直接定位。真实按钮回归记录中间位置，检查减速、方向、终点、四至六行月份、短月、连续点击、反向、中断与边界，并复查返回今天和吸附路径。将箭头临时恢复为直接定位时，中间位置断言失败，证明该检查能拒绝旧行为。采样不能证明窗口服务器帧率、物理交互手感或所有系统版本；系统减少动态效果开启时跳过运动采样。
