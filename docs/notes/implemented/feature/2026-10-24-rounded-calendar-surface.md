# Agent Note: Rounded Calendar Surface

Status: implemented

## Problem

月视图中间实色日期区横向铺满弹窗，上下直线边界割裂外围材质。圆角设计需要露出四角和侧边，同时避免缩窄七列日期、裁掉四字节日或改变连续滚动布局。

## Decision

日期区整体采用连续圆角裁剪，背景与原生滚动视图一起裁剪；原生滚动容器自身也设置同一圆角与图层裁剪，防止子视图刷新后越过 SwiftUI 的边界。外围由一层固定系统材质连接顶部和底部，关闭毛玻璃时使用既有实色替代。将原来的行内左右留白拆分为卡片外边距与行内边距，保留日期列宽；星期栏使用等宽、无额外间隔的七列与日期中心对齐。跨月标题和周行分隔线沿用同一内边距。月视图隐藏原生垂直滚动条，避免滚动时覆盖右侧日期和破坏卡片边缘；保留原生滚动容器及其滚轮、触控板和吸附行为。

此决定部分取代[弹窗材质](2026-10-23-popover-material.md)的月视图直线边界与上下独立材质布局，保留其实色内容底色和系统外观适配。圆角不改变滚动视口高度、周行高度、日期选择和吸附状态的所有权。

## Alternatives considered

- 保留横向铺满的实色区：可用空间充足，但不能形成设计图中的内嵌圆角外观。
- 直接给现有日期区增加外边距：会在既有内边距之外继续压缩七列宽度，影响四字节日与休班标记。
- 为每一天添加圆角卡片或明显阴影：增加视觉分割，不服务于日期区整体圆角的目标。

## Consequences

月视图的上下分隔改由圆角区域边缘表达；年概览的对应调整见[年概览圆角设计](2026-10-24-rounded-year-overview.md)。卡片外边距属于固定背景，随桌面背景和毛玻璃偏好变化。快照覆盖设计日期、深浅色、长节日名称与毛玻璃开关，真实滚动验证覆盖四至六行月份、跨月浏览和位置恢复；窗口服务器的材质透色与物理触控板体验仍需人工检查。

月视图与年概览之间的容器和日期正文衔接由[日期缩放过渡](2026-10-24-calendar-zoom-transition.md)补充，滚动视口和位置恢复仍由原有连续日历负责。
