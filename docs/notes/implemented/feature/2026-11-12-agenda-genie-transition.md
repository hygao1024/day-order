# Agent Note: Agenda Genie Transition

Status: implemented

## Problem

周内日程原先随行高变化直接显现，无法表达卡片来自哪个日期。用户要求从点击日期所在列向四周展开，起点与日程灰底的真实顶部一致，保留上方标记或日期选中背景到日程的既有间距，并在收起时产生吸回效果。

## Decision

部分取代[当天日程展开](2026-11-10-inline-day-agenda.md)的卡片呈现方式，保留固定窗口、周行布局与滚动行为。详情快照记录同周日期单元身份，横向跟随点击列，纵向直接使用日程单元位置加灰底顶部内缩。灰底绘制与动画共用顶部内缩值；整周最下方标记下方 8 pt、无标记时选中日期背景下方 8 pt 的定位继续由真实布局拥有，动画不重新计算标记高度或再次增加间距。

最初日程快照按目标像素水平分条，顶部晚于底部向两侧展开，形成短暂的曲面窄颈；顶部透明内缩随快照一起变形，保证可见灰底顶边保持在既有间距下方。动画背景直接调用原生日程的背景绘制，复用 `CalendarSurface.selectionBackgroundColor` 及其透明度；动画快照仅保存列表内容，采集时临时隐藏背景并在结束或失败后恢复。完整周行快照继续用于普通淡化，但曲面不回放其中的背景，防止冻结底色或重复叠加。背景与文字交叉淡化分开合成，避免文字的预乘透明度影响底色。原生列表仍拥有滚动、文字选择和无障碍语义；动画结束后交还原生列表。按目标像素对齐接缝，避免半透明背景重复合成产生横纹。日期与农历不变形。

早期真实 Retina 窗口中直接执行透明条带绘制会出现底色变深、文字重影及色条偏色，而相同视图的离屏采样未复现。当时整帧曲面因此先在透明位图中完成，再一次合成到屏幕；背景仍调用原生日程的绘制，不维护独立实色。条带按位图上下文的物理像素裁切。真实窗口截图比较用于覆盖离屏检查遗漏的合成路径。

展开量与既有周行运动共用展示控制器的弹簧和显示驱动，不增加定时器、持久状态或依赖。重定向保留未扭曲的底图与当前展开量、速度，防止反复扭曲已经变形的图像。正常收尾同时等待形状收敛；减少动态效果沿用短淡化，关闭与页面切换沿用原控制器的清理边界。

动画形态现由[日程向下展开](2026-11-13-agenda-vertical-reveal.md)部分取代，以详情灰底顶部为固定边缘，保持完整宽度直接向下揭示内容，已移除条带与 GPU 曲面。本文继续拥有 8 pt 间距、原生列表交接与反向状态的决定；日期列身份已随横向展开一并移除。

## Alternatives considered

- 仅改变速度或统一缩放卡片：缺少从日期底部伸出的曲面与来源关系。
- 只改变遮罩轮廓：文字原地露出，无法呈现卡片内容随曲面展开的效果。
- 直接向屏幕绘制条带，仅调整像素步长或透明隔离层：真实 Retina 窗口仍可复现颜色差异，不能以离屏检查通过代替窗口验证。
- 引入独立图形渲染层或动画驱动：现有位图展示层已拥有端点与中断状态，额外驱动会增加同步与清理责任。

## Consequences

静止布局保持不变，最初曲面中的文字会短暂压缩；当前方案保持原始字形。早期逐像素分条及每帧透明位图增加过渡绘制与分配工作，这一开销已由上述缓存内容的裁切揭示替代；高刷新率手感仍需真实设备体验。深浅色、左右日期、展开收起、反向、减少动态效果，以及胶囊／横线／圆点模式下整周无标记和仅其他日期有标记的起点由真实窗口专项覆盖，采样方法与限制由[界面验证参考](../../../verification.md)维护。
