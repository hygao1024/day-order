# Agent Note: Agenda Vertical Reveal

Status: implemented

## Problem

[日期起点曲面动画](2026-11-12-agenda-genie-transition.md)及其 GPU 连续形变版本虽降低了绘制开销，仍未达到期望的连贯观感。用户取消神奇效果后，先后试用了整体等比缩放与横线先扩宽再向下展开；现在明确取消横线起步，要求直接非线性向下展开。

## Decision

部分取代原记录的动画形态，保留原布局拥有的整周内容下方 8 pt、共享背景和原生列表交接。详情从零高度开始，全程保持完整宽度，纵向直接复用灰底顶部，避免另算标记高度与重复加间距。动画单元仅区分日程和普通日期内容，不再记录用于横向起线的日期单元身份。

高度直接复用既有无回弹弹簧的非线性进度，没有分阶段映射、起线高度或暂停计时器；收起与快速反向接续同一进度和速度。内容只缓存原尺寸透明快照，用圆角裁切逐步揭示，避免压扁字形。背景每帧复用原生绘制一次，半径随高度限幅到 8 pt，文字交叉淡化仍在隔离层内插值预乘颜色，底色不参与叠加。

移除 Core Image/Metal 曲面内核、GPU 预热及回读、窄颈/底边分段时序和 GPU 不可用回退；减少动态效果继续使用既有短淡化。缓存随动画单元重定向替换，结束或取消时释放，没有新时钟、依赖或持久状态。原生列表仍拥有滚动、选择与无障碍行为。

## Alternatives considered

- 继续调整曲面上下两端时序：用户已明确放弃这一视觉方案。
- 保留 GPU 形变作为备用模式：没有当前消费者，会继续承担边界采样、显示倍率和资源生命周期成本。旧内核曾在 1× 屏幕把半透明边缘延展到曲面外。
- 从点整体等比缩放：包含横向缩放和字形变化，不符合直接向下展开的要求。
- 标记等宽横线先扩宽再增高：用户已取消这一阶段；删除起线宽度计算与分阶段进度映射，避免残留等待。
- 横纵分别缩放内容：会压扁文字；保留原尺寸内容并裁切更符合这次展开形态。
- 两个串联动画或单独等待：会增加中断状态和衔接停顿的风险。
- 逐帧生成位图或按像素条带绘制：增加分配和合成开销；此前条带在真实 Retina 窗口出现颜色加深，必须保留真实窗口颜色检查。当前仅简单背景填充及缓存内容裁切，无逐帧位图重建。

跨周切换时的入场与退场位置联动见[日程跟随周行运动](../bug-fix/2026-11-13-agenda-week-motion.md)。

## Consequences

静态尺寸、颜色和间距不变，文字在展开边缘被逐步揭示而非缩放。背景来自原生详情的相同半透明底色，不单独提高颜色强度。详情与下方周行共用现有运动时钟，从动画开始一起展开和让位。

真实视图专项覆盖零高度起点、全程完整宽度及立即增高、固定顶边、连续进度、深浅色背景、反向、长短列表及真实逐帧与交接计时；双倍率真实窗口检查补充离屏采样，不能据此承诺物理屏幕帧率或主观手感。验证入口及覆盖限制见[界面验证参考](../../../verification.md)。
