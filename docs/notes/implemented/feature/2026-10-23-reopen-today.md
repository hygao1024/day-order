# Agent Note: Reopen Today

Status: implemented

## Problem

弹框复用同一个模型，之前浏览的月份、设置页面或年份草稿会留到下一次打开。用户要求每次打开都回到今日。

## Decision

在弹框的统一打开入口先刷新设备当前日期，再退出设置、清空年份草稿并选择今天。选择日期沿用模型已有逻辑，同步恢复本月、退出年月选择器。只重置本次浏览状态，所有持久化显示偏好继续保留。

## Alternatives considered

- 关闭时重置：关闭到下一次打开可能跨天，仍需在打开时刷新，且关闭路径更多。
- 每次重建整个模型和视图：可以清除界面状态，但增加生命周期成本；现有状态具有明确所有者，直接复位即可。

## Consequences

重新打开不再恢复上次浏览位置。真实入口验证从异月、设置及含无效草稿的年月选择器关闭后重新打开，同时模拟过期的今天，断言回到当前日期且偏好未变。测试临时固定浮层以隔离自动化宿主失焦；外部点击关闭行为仍交由原生临时浮层负责。
