# Agent Note: Calendar Zoom Transition

Status: implemented

## Problem

月视图与年概览直接替换内容时，圆角容器尺寸和日期排布同时跳变，用户难以跟踪当前月份在年概览中的位置。需求是让日期正文缩小到对应小月历，顶部月份和星期字样不参与缩放，并保持已有日期选择与连续滚动语义。

## Decision

运动节奏、内容淡化和中途重定向现由[连续日历运动](../bug-fix/2026-10-24-continuous-calendar-motion.md)取代：原有 220 ms 三次缓出、上下栏文字直接更新及反向直接结束不再是当前行为。本文保留快照端点、常驻容器、显示刷新驱动和生命周期约束的原始理由。

由弹窗展示控制器持有一次过渡的准备任务、刷新驱动、快照和临时绘制层。模型仍只拥有选择、浏览月份和导航状态；原生日期按钮提供实际可见数字的几何、字形和今天标记。月历和小月历的数字位置分别复用各自日常绘制的几何来源，不另造全年逐日视图。

切换前读取旧页面，下一次布局后读取目标页面。快照暂时隐藏被转交的数字，随后立即恢复；滚动正文单独取样，避免把原容器的圆角和外围材质叠加到移动中的容器。临时层只对两端共有的日期数字与今天红圈插值，位置、字号、字重和容器尺寸最初使用同一个三次缓出进度，快速启动后单调减速，无回弹；较短的时长减少慢启动和尾部拖延。正文的其他内容分阶段淡化，避免农历与其他小月历重叠。原方案对上下栏快照使用互补权重合成，避免正文先出后入造成的中段空白，但未消除真实材质与临时材质交接；该部分由[常驻日历外壳](../bug-fix/2026-10-24-persistent-calendar-chrome.md)取代。遮在浮动年份标题下面或被视口截断的数字保持淡化，不建立虚假的缩放端点。

Published（发布属性）在赋值前通知订阅者，原生快照绘制可能同步消费这次 SwiftUI 刷新。因此读取终点前，在赋值后的主线程轮次补发界面刷新通知，再等待布局；不把旧页面的截图误作终点。首次打开即切换的年概览回归覆盖这个时序。

来源月份取浏览月份，而不是已选日期。点击其他小月历时，现有导航先更新目标月，再离开概览，因此反向过渡从被点击的小月历读取数字。返回自由滚动页面仍由原有可见周和偏移恢复，不保存列表内部的绝对纵坐标；原生表格重新建立时，已求值行高可能使绝对坐标改变。

展示控制器对每次请求分配修订号。快速反向结束旧动画并显示最新页面，设置、关闭与退出移除临时层并恢复真实视图。取消后迟到的任务不能清理后来的请求。快照不可用时直接显示目标页面；日期缩放没有共同可见日期或开启减少动态效果时仅短淡化。动画不写选择、不安排网络请求、不持久化临时状态。设置仅取消旧动画的规则由[设置容器过渡](2026-10-24-settings-container-transition.md)扩展：没有正在进行的过渡时，进入与返回设置复用容器形变，不建立日期配对。

嵌套的托管控制器在布局完成后报告真实内容尺寸，保证动画之外的日历详情仍能改变弹窗高度。设置高度改由[统一设置页面](2026-10-24-rounded-settings-surface.md)约束为入口高度。外观偏好继续由既有设置解释，并显式传给拥有窗口的弹窗；不能依赖嵌套托管视图向上传递配色偏好。

此决定补充[年概览圆角设计](2026-10-24-rounded-year-overview.md)和[月视图圆角设计](2026-10-24-rounded-calendar-surface.md)的页面切换行为，保留原生列表、日期选择、滚动吸附和返回今天的所有权。

逐帧驱动与布局测量的责任由[显示同步缩放](../architecture/2026-10-24-display-synchronized-calendar-zoom.md)更新，保留这里的日期端点、曲线和降级语义。

## Alternatives considered

- 整页直接缩放截图：会同时压缩顶部按钮、星期、农历和详情，无法把当前月份准确落到小月历。
- 将日期改为逐个 SwiftUI 视图并使用共享几何过渡：会改变现有原生绘制与列表复用，扩大连续滚动的性能风险。
- 对称缓入缓出：起步阶段移动较少，叠加页面准备时间后显得迟缓；改为快速起步的缓出曲线。
- 只做交叉淡化：实现更小，但无法建立当前月与年概览小月历的空间对应；保留为减少动态效果及端点不可见时的降级路径。

## Consequences

临时位图只在短过渡内存在，成本随弹窗可见区域而非年份范围增长。仅暂停中央正文的可见绘制，完成或取消后恢复其交互；上下栏和材质不由快照接管。中途 Esc 可立即返回，关闭仍由现有弹窗生命周期负责。

专项冒烟使用真实弹窗采样日期和容器连续变化，并检查前半程位移领先时间进度、常驻上下栏和背景在开始、过程中及结束后的身份与可见性；另覆盖布局尺寸、正反向、边界年份、星期起始、自由滚动恢复、取消与短淡化。深浅色同时检查原生有效外观和快照，避免仅按截图文件名认定外观正确。视图快照无法完整证明窗口服务器的材质合成、显示帧率或物理操作手感；这些保留人工检查。
