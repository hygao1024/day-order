# Agent Note: Calendar Event Marker Morphing

Status: implemented

## Problem

日期格截图能够保持日期字形和位置连续，却只能混合两个日程外观，无法表达胶囊压扁、横线收拢和圆点淡出。连续点击还需要接续标记正在显示的形状和透明度，而不是从上一个模式重新播放。

## Decision

部分取代[四档正文缩放](2026-11-06-calendar-mode-animation.md)中的事件截图混合：日期底图采集时临时排除事件标记，并可靠恢复真实按钮；静态末态与过渡共同使用胶囊矢量绘制器。标记按日期格、事件标识和实例开始时间匹配，避免重复事件合并。每个标记的矩形、整体透明度、底色强度和详情透明度与正文共用系统弹簧和显示刷新回调；圆角半径随高度变化，文字保持原生大小并随可用空间渐隐。

重定向只修改终点，保留当前值与速度，日期底图的再次合成不包含标记。收起时保留原胶囊标题，避免更多计数在淡出前变成某条事件名。进入隐藏立即清空事件库；展示层仅在短过渡中保留离场外观，不查询权限或事件。新出现的标记从透明圆点展开，消失的标记收拢到透明圆点；收拢点置于隐藏行高可容纳的位置，避免被缩小后的日期区裁切。结束、导航、关闭和页面交接沿用原展示层清理，减少动态效果沿用短淡化。

## Alternatives considered

- 混合包含事件的日期截图：有淡化但没有真实形状中间态，还会让快速切档的旧标记残留在底图中。
- 为四档分别创建视图并做插入／移除动画：身份和运动状态容易在替换时丢失，无法保证快速点击承接当前形状。
- 给标记单独启动定时器：与正文和窗口的刷新节奏、取消及交接产生第二个所有者。

## Consequences

静态布局不变的约束由[连续跨日日程](2026-11-06-continuous-calendar-events.md)部分取代；仍使用每日期格的标记身份及同一运动状态，跨日段收拢到各格内的圆点。权限和数据归属不变，只有短过渡增加少量可见标记状态。真实视图专项覆盖深浅色、实际中间态像素、重复实例、更多计数、连续点击值和速度接续、隐藏的零访问及减少动态效果；隔离副本分别跳过形变、跳过矢量绘制时，专项必须失败。正文缩放和权限按钮继续运行原短专项，不运行全流程。几何与像素证据不代表物理帧率、系统授权窗或真实账户同步，仍由实机验证。
