# Agent Note: Menu Bar Display

Status: implemented

## Problem

固定的图标、月日和星期组合无法适应用户对完整日期或更少菜单栏占用的需求。仅显示静态图标时，用户仍需展开才能知道今天几号。

## Decision

以独立的显示方式和日期格式偏好控制菜单栏，沿用 UserDefaults 持久化及现有设置界面。设置变化立即通知 AppDelegate 刷新；启动、跨天、唤醒、时区变化和定时刷新都经过同一投影。未知偏好值回退默认显示，避免状态栏入口消失。具体选项与默认值由 README 拥有。

日期格式由核心枚举产生，界面与状态栏消费者共享稳定取值。动态图标采用用户选定的圆角实心底与镂空数字，由 AppKit 绘制为单色模板，系统负责菜单栏明暗适配；数字从应用的今天取值，与月历选择分离。悬停和无障碍标签保留完整日期，即使只显示图标也能获取上下文。

## Alternatives considered

- 开放日期格式字符串：自由度更高，但引入格式语法、空输出和不合理长度等边界；当前需求由明确的常用格式覆盖。
- 只使用系统静态日历符号：省去绘制，但无法表达当天数字。
- 监听所有偏好变化：能够响应外部写入，但应用内仅一个设置入口，显式变化回调无需额外观察者生命周期。

## Consequences

用户切换到仅图标时保留原日期格式。新偏好与测试偏好使用相同存储实例，调试验证不会污染日常设置。核心测试检查日期格式；真实状态栏冒烟验证检查偏好即时生效、独立实例读取、回退、日期刷新和图标快照。图标在本机浅深色外观下检查，其他 macOS 版本及旁白操作仍需人工验证。
