# Agent Note: Capsule Month Navigation

Status: implemented

## Problem

月视图右上角三个独立灰底按钮割裂了同一组月份导航操作。设计稿采用一体胶囊，需要在紧凑标题行中保持三个动作可辨认、可独立命中，并继续表达范围边界的禁用状态。

## Decision

使用单层胶囊底色和细轮廓包裹三个 SwiftUI 按钮，短竖线区分操作区域；每个按钮独立提供悬停、按下与禁用反馈。整体轮廓裁剪反馈背景，装饰层不参与命中。保留原有按钮动作、提示和无障碍语义，导航状态仍由应用模型拥有。

这是一组即时动作，不能用持续选中的分段选择器表达。“今天”与左右箭头使用不同宽度以容纳中文，同时为双位月份标题保留空间。年概览的导航属于另一层级，保持原样。

## Alternatives considered

- 仅增大三个原有按钮的圆角：仍留下三个独立底色，无法形成设计稿中的整体轮廓。
- 使用分段选择器：会引入与即时切月动作不符的选中状态。

## Consequences

按钮样式局限于月视图导航，不影响日期区、设置或年概览。自定义背景需要显式处理禁用颜色；禁用行为继续由按钮和模型共同约束。真实入口冒烟用无障碍标签定位并点击三个按钮，检查月份变化、返回今天与边界无动作，快照覆盖深浅色布局。旁白朗读、键盘焦点外观和不同系统版本仍需人工验证。
