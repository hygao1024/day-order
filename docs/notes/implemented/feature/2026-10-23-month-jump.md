# Agent Note: Month Jump

Status: implemented

## Problem

逐月点击箭头无法快速浏览相距多年的月份。用户希望从左上角年月直接跳转，且日历仍应保持紧凑。

## Decision

将年月标题作为入口，在原弹框内切换为年份输入和十二个月份按钮。输入年份只编辑草稿，点击月份才提交；取消时保留原选择。沿用现有年份范围，按目标年月直接构造日期，跳转保留日号，短月取月末。跨年大跨度月份累加在本机将 2026-01-31 跳到 2024-02-28，因此使用目标月份实际天数截断，确保闰年得到 2 月 29 日。模型在执行边界检查年、月，避免仅依赖按钮禁用。

选择器状态归应用模型所有，键盘监控和 SwiftUI 共用此状态。选择器展开时，方向键等事件交还输入控件，Esc 只退出选择器；普通月历仍使用原导航快捷键。

## Alternatives considered

- 嵌套弹出窗口：增加弹框焦点和关闭关系，原地切换更适合现有状态栏浮层。
- 仅使用年份下拉列表：覆盖范围较大时需要滚动，直接输入能更快跨越多年。
- 选择年月后总是回到 1 日：简单但改变已有逐月导航保留日号的习惯。

## Consequences

无需额外持久化或依赖。真实入口验证覆盖年份输入、取消、跨年跳转、闰年和短月、上下界、无效年月份拒绝，以及浅深色布局。键盘验证临时固定测试浮层，隔离宿主抢焦点的影响；外部点击关闭仍由生产环境的原生临时浮层处理，本次不声称覆盖其端到端交互。未新增系统日历权限。
