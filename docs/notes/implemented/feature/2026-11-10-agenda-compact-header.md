# Agent Note: Compact Agenda Header

Status: implemented

## Problem

日程卡片顶部重复展示日期、总数与收起控件，并通过尖角指向日期。用户希望使用纯圆角矩形，移除这些文字和装饰，保持页面简洁。

## Decision

部分取代[当天日程展开](2026-11-10-inline-day-agenda.md)的固定文字标题与关闭按钮。移除标题视图、收起控件及其回调、尖角绘制与定位数据；卡片仅保留圆角背景和正文，将顶部占用由 32 pt 收紧为 12 pt 留白。日期与总数保留在列表的无障碍标签中，通过再次点击已展开日期或 Esc 收起。正文、剩余数量提示和展开会话规则不变。

## Alternatives considered

- 仅清空标题文字但保留原高度：留下无用途的空白，无法达到精简卡片的目的。
- 保留无文字的收起箭头：用户明确不需要，现有日期点击与键盘入口已经支持收起。

## Consequences

最大详情高度与实际布局共用顶部留白，边缘动画继续按完整详情范围采样。原交互检查改为通过真实内容、事件数量和无障碍标签识别详情，保留关闭、导航和滚轮分发检查。真实深浅色快照用于确认纯圆角外形与正文留白，并更新产品展示图；未以此声称完整旁白操作已验证。
